# 오늘 옷 코디네이터

옷장 사진 분석 → 날씨별 코디 추천 → 내 사진 위 착장 미리보기 · AI 착장/헤어 생성(Gemini) 웹앱. 서버 없이 브라우저에서만 동작하는 정적 사이트입니다.

## 사용법
1. 주소를 엽니다(GitHub Pages). 폰이면 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있어요.
2. **⚙️ 설정**에서 [Google AI Studio](https://aistudio.google.com/apikey)에서 만든 Gemini API 키를 붙여넣고 "저장 후 연결 테스트"를 누릅니다.
3. **내 모습** 탭에서 전신 사진 등록 → **오늘 코디** 탭에서 `✨ AI로 내 모습에 입혀보기`.
4. 키가 없거나 무료로 쓰려면 `무료: Gemini 앱으로`(B 방식): 시트 이미지와 프롬프트를 Gemini 앱에 붙여넣어 만든 뒤 결과를 올려 기록합니다.

## 개인정보·비용
- 옷·내 사진·API 키는 **이 브라우저(IndexedDB)에만** 저장됩니다. 저장소에는 어떤 키도 사진도 없습니다.
- AI 기능을 누를 때만 해당 사진/정보가 Google(Gemini API)로 전송됩니다. 무료 등급은 입력이 Google 제품 개선에 쓰일 수 있으니 전신 사진은 결제 설정된 키로 쓰는 것을 권장합니다.
- 이미지 생성은 계정에 따라 유료일 수 있습니다. 요금은 Google 안내를 확인하세요.
- 키가 담긴 주소를 타인에게 공유하지 마세요(키는 각자 브라우저에 저장되므로 주소 공유만으로는 키가 새지 않지만, 타인이 자기 키를 넣어 쓰는 구조입니다).
